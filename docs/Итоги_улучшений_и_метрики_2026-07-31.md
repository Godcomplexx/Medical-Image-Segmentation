# Итоги улучшений и финальные метрики модели (РС, детекция + классификация очагов)

**Дата:** 2026-07-31
**Модель:** двухэтапный каскад — детектор очагов (2.5D U-Net, ResNet34) + анатомический классификатор I/P/S/U (HistGradientBoosting на масках SynthSeg).
**База сравнения:** `docs/МРТ_РС_ИИ_детекция_классификация_очагов.docx` и `docs/Описание_модели_и_метрик_MS.docx`.

---

## 1. Краткий итог

- **Классификатор существенно улучшен:** macro-F1 при найденном очаге **0.638 → 0.845** (реальные маски SynthSeg + правила врача).
- **Детектор:** recall на клинически значимых очагах (**≥100px**) = **0.812**; precision улучшена **0.58 → 0.68** (меньше ложных срабатываний).
- **Сквозная модель ≥100px:** macro-recall **0.589** = уровень статьи (0.59), воспроизведён на большем и более тяжёлом val.
- Всё реализовано **по подтверждённым правилам врача**, без машинно-выдуманных очагов.

## 4. Что реализовано (изменения)

1. **Переобучение детектора** на полной разметке доктора (9923 среза, проверено — без машинных дополнений/LST) при imgsz 896.
2. **Устойчивое обучение:** `train_seg --resume` (полный чекпойнт каждую эпоху) + запуск отвязанным процессом — переживает обрыв сети/закрытие терминала.
3. **Маски SynthSeg** сгенерированы на 202 исследования (кора, желудочки, мозжечок, ствол); выравнивание `seg[:,:,z]` со срезами подтверждено.
4. **Классификатор на реальных масках** вместо FLAIR-прокси (расстояния/контакты до коры и желудочков).
5. **ГЛАВНАЯ ПРАВКА — класс I по анатомии:** новый признак `infra_contact_norm` (перекрытие с мозжечком/стволом) вместо костыля `z_norm`.
6. **Правило врача для U:** `--cortex-relabel` — очаг с ≥50% площади в коре → U (через маску SynthSeg). U: F1 0.35 → **0.80**, попутно S: 0.74 → 0.86.
7. **Согласованная оценка:** `evaluate_seg --min-gt-area 100` для честного режима ≥100px.

## 5. Проверено и НЕ даёт улучшения (чтобы не повторять)

- **Признаки формы очага** (из полигонов датасета): прироста нет (macro-F1 −0.011) — репроцессинг смывает форму.
- **Обучение детектора с фильтром ≥100px** (согласовать правило train=val): **хуже** (recall@≥100px 0.812 → 0.689) — убрав мелкие, лишаем модель сигнала. Правильно: учить на всех, оценивать на ≥100px.
- **Distillation / псевдо-метки** (LST-AI/nnU-Net дозаполняют разметку): риск добавить **не-очаги** (дисциркуляция, артефакты) — отклонено как порча GT.
- **Больше данных (`--full`), imgsz↑, 2.5D vs 2D, полный 3D nnU-Net:** потолок recall детектора не двигают (абляция это подтверждает).

## 7. Выводы и оставшиеся рычаги

- **Классификация** при найденном очаге фактически на потолке (0.845); мелкий резерв — признак «перпендикуляр Доусона» для P.
- **Детектор** на клинически значимых очагах (≥100px) хорош (0.812). Пропуски — в основном мельчайшие <100px, которые правило и так отсекает.
- **Разметка полная и верная** (подтверждено врачом — пропущенных реальных очагов нет), поэтому рычага «дозаполнить данные» нет.
- Единственный недорогой незакрытый код-рычаг — **обмен precision→recall** (порог/α) на детекторе: можно выжать последние пункты recall@≥100px ценой точности (есть запас precision 0.68 против docs 0.58).
- **Больше размеченных исследований (напр. +100)** поможет прежде всего **редким классам** (I: сейчас всего 8 очагов ≥100px — оценка ненадёжна) и **сузит доверительные интервалы**; общий recall-потолок детектора при этом сдвинется слабо (масштабирование данных ×3.6 его почти не двигало). Условие: новые исследования должны быть размечены доктором.
