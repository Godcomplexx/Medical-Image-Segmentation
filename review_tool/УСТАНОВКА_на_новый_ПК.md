# Установка инструмента разметки на новый компьютер (для врача)

Просто скопировать папку — **недостаточно**: виртуальное окружение `.venv-*`
привязано к исходному компьютеру (путь к Python и имя пользователя) и на новом ПК
не запустится. Его нужно **пересоздать**. Ниже — по шагам.

Нужно один раз настроить, дальше врач только запускает `.bat`.

---

## 0. Что перенести на новый ПК

Скопируйте папку проекта, но **БЕЗ** тяжёлых и непереносимых папок:

Обязательно нужны:
- `review_tool\` — сам инструмент и эта инструкция;
- `finetune\fileStorage\nnunet_env\` — веса обученной модели nnU-Net (главное!);
- `finetune\src\` — конвертер DICOM→NIfTI;
- три батника в корне: `Разметка_очагов_GUI.bat`, `make_review_annotations.bat`,
  `Принять_правки.bat`.

**НЕ копируйте** (пересоздадутся / не нужны врачу):
- `.venv-train\`, `.venv-samseg\` — окружения (сломаны на новом ПК, создадим заново);
- `front\node_modules\` — не нужно для разметки;
- папки `review_tool\input`, `review_tool\output`, `review_tool\accepted` — рабочие.

Проще всего: скопировать всю папку целиком, а потом на новом ПК **удалить**
`.venv-train` и `.venv-samseg` (мы их пересоздадим).

---

## 1. Установить Python 3.12

1. Скачать Python **3.12.x** (64-bit) с https://www.python.org/downloads/
2. При установке поставить галочку **«Add python.exe to PATH»**.
3. Проверить в PowerShell: `py -3.12 --version` → должно показать `Python 3.12.x`.

## 2. Установить 3D Slicer

- Скачать с https://download.slicer.org (стабильную версию), установить.
- В Slicer врач будет проверять и править разметку (см.
  `КАК_ПРОВЕРИТЬ_в_Slicer.txt`, он создаётся рядом с результатами).

## 3. (Желательно) Видеокарта NVIDIA

- Модель nnU-Net считает быстрее на GPU. Нужен свежий драйвер NVIDIA.
- **Без видеокарты тоже работает**, но одно исследование обрабатывается заметно
  дольше (минуты вместо секунд). Если GPU нет — на шаге 4 ставьте CPU-сборку torch.

---

## 4. Создать окружение и поставить зависимости

Откройте **PowerShell** в корне папки проекта (там, где лежат `.bat`) и выполните.

Замените `D:\Medical-Image-Segmentation` на реальный путь, если папка лежит в другом
месте.

```powershell
cd D:\Medical-Image-Segmentation

# создать чистое окружение
py -3.12 -m venv .venv-train
.\.venv-train\Scripts\python.exe -m pip install --upgrade pip

# 1) torch — ставится ОТДЕЛЬНО, с официального индекса PyTorch:
#    --- вариант с видеокартой NVIDIA (CUDA 12.6): ---
.\.venv-train\Scripts\python.exe -m pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu126
#    --- ИЛИ вариант без видеокарты (CPU): ---
# .\.venv-train\Scripts\python.exe -m pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cpu

# 2) все остальные зависимости:
.\.venv-train\Scripts\python.exe -m pip install -r review_tool\requirements-review.txt
```

> Если видеокарты нет — раскомментируйте (уберите `#`) строку CPU и **не** запускайте
> строку CUDA. Версии torch можно взять и новее, если 2.10.0 недоступна для вашей CUDA.

---

## 5. Поправить путь в батниках (если папка НЕ на `D:\Medical-Image-Segmentation`)

Если проект лежит по другому пути — откройте **каждый** из трёх `.bat` в «Блокноте»
и поменяйте одну строку:

```
set "REPO=D:\Medical-Image-Segmentation"
```
на реальный путь, например `set "REPO=C:\MS\Medical-Image-Segmentation"`.

Файлы: `Разметка_очагов_GUI.bat`, `make_review_annotations.bat`, `Принять_правки.bat`.

---

## 6. Проверка, что всё встало

```powershell
.\.venv-train\Scripts\python.exe -c "import torch, nnunetv2, nibabel, cv2, scipy; print('OK, cuda=', torch.cuda.is_available())"
```
Должно напечатать `OK, cuda= True` (или `False`, если работаете на CPU — это тоже
нормально).

Затем положите одно тестовое исследование в `review_tool\input` (папку DICOM или
файл `.nii.gz`) и запустите `make_review_annotations.bat`. В `review_tool\output`
должны появиться папки с `*_FLAIR.nii.gz`, `*_seg.nii.gz` и инструкцией для Slicer.

---

## Как этим пользуется врач (после установки)

1. **`make_review_annotations.bat`** — перетащить на него папку с исследованиями
   (или положить их в `review_tool\input` и дважды кликнуть). Модель находит очаги и
   раскладывает результат в `review_tool\output`.
2. Открыть результат в **3D Slicer**, проверить/поправить (инструкция —
   `КАК_ПРОВЕРИТЬ_в_Slicer.txt` рядом с результатами).
3. **`Принять_правки.bat`** — превращает проверенную разметку обратно в обучающий
   формат (`review_tool\accepted`).
4. **`Разметка_очагов_GUI.bat`** — графическая оболочка над тем же процессом.

---

## Частые проблемы

- **«Не найдено окружение .venv-train»** — не выполнен шаг 4, либо неверный `REPO`
  в `.bat` (шаг 5).
- **`nnUNetv2_predict` не найден / ошибка nnU-Net** — не поставился `nnunetv2`
  (шаг 4, п.2) или не скопирована папка `finetune\fileStorage\nnunet_env`.
- **Кириллица в путях ломает конвертацию DICOM** — держите исследования в путях
  без русских букв (инструмент сам использует ASCII-временную папку, но лишний риск
  ни к чему).
- **Очень медленно** — работаете на CPU. Это ожидаемо; для скорости нужна NVIDIA GPU
  и CUDA-сборка torch (шаг 4).
