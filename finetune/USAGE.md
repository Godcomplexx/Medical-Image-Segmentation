# Инструкция по использованию модуля Finetune

Этот документ описывает, как использовать модуль `finetune` для дообучения модели YOLO на медицинских изображениях.

## Обзор

Модуль `finetune` предназначен для автоматической подготовки данных и дообучения модели YOLO для сегментации特定 областей на DICOM-изображениях. Процесс включает в себя конвертацию DICOM в NIfTI, создание изображений и масок (меток) для YOLO, и последующее дообучение модели.

## Структура директорий и форматы файлов

### Входные данные

Все входные данные должны быть размещены в директории `finetune/fileStorage/input_data/`.

Для каждого случая (пациента) необходимо создать отдельную папку. Название папки будет использоваться как идентификатор случая.

Внутри каждой папки случая должны находиться:
1.  **DICOM-файлы:** Папка `DICOM`, содержащая серии DICOM-изображений.
2.  **Файлы разметки:** Папка `Markups` с файлами разметки в формате `.mrk.json` (стандартный формат 3D Slicer).

**Пример структуры:**
```
finetune/
└── fileStorage/
    └── input_data/
        └── <ID_пациента_1>/
            ├── DICOM/
            │   ├── ST000000/
            │   │   ├── SE000000/
            │   │   │   └── ... (файлы DICOM)
            │   │   └── ...
            └── Markups/
                ├── S_10.mrk.json
                ├── U_1.mrk.json
                └── ...
        └── <ID_пациента_2>/
            └── ...
```

### Файлы разметки (`.mrk.json`)

-   Это JSON-файлы, содержащие координаты контрольных точек для создания масок сегментации.
-   Имя файла должно начинаться с префикса, который соответствует классу в `finetune/config/labeling_config.py` (например, `I`, `P`, `S`, `U`).

## Процесс использования

Процесс состоит из двух основных этапов: подготовка датасета и дообучение модели.

### Шаг 1: Подготовка датасета

Для запуска процесса подготовки данных выполните скрипт `yolo_dataset.py`:

```bash
python -m finetune.src.pipelines.yolo_dataset
```

Этот скрипт выполнит следующие действия:
1.  Просканирует директорию `finetune/fileStorage/input_data/`.
2.  Для каждого нового случая (папки, которая еще не обработана) выполнит:
    -   Конвертацию DICOM-файлов в формат NIfTI (`.nii.gz`).
    -   Генерацию PNG-изображений (срезов) из NIfTI-файла.
    -   Создание текстовых файлов с метками (`.txt`) для YOLO на основе `.mrk.json` файлов.
3.  Промежуточные и конечные файлы будут сохранены в `finetune/fileStorage/processed_data/`.

### Шаг 2: Дообучение модели

После подготовки датасета запустите скрипт `yolo_finetuning.py` для дообучения модели:

```bash
python -m finetune.src.pipelines.yolo_finetuning
```

Этот скрипт выполнит:
1.  Перемещение подготовленных изображений и меток в `finetune/fileStorage/train_set/`.
2.  Разделение данных на обучающую (`train`) и валидационную (`val`) выборки.
3.  Создание конфигурационных файлов для YOLO (`config.yaml` и `hyp.yaml`) в директории `finetune/yolo_config/`.
4.  Запуск процесса дообучения модели YOLO.

### Выходные файлы

-   **Подготовленный датасет:** `finetune/fileStorage/train_set/`
-   **Логи:** `finetune/logs/`
-   **Обученная модель:** `finetune/best.pt` (сохраняется после завершения обучения).

## Конфигурация

Основные параметры, такие как пути к директориям, гиперпараметры YOLO и настройки классов, можно изменить в следующих файлах:

-   `finetune/config/settings.py`: Основные пути и гиперпараметры.
-   `finetune/config/labeling_config.py`: Соответствие между классами, цветами и префиксами файлов разметки.
